## 一句话概括

情报检索是架在攻击样本库上的查询层。它把蜜罐采集到的攻击流量按结构化字段入库，让分析者用字段和 DSL 直接找攻击，而不是翻日志。

## 原理

攻击流量实时入库形成攻击样本库，检索层在其上提供字段检索和 DSL 检索。

成因：日志里平铺的请求原文回答不了"哪些 IP 用某个载荷打过这条路"这类问题。只有把攻击位置、攻击载荷、攻击类型抽成独立字段，才能按维度筛选和聚合，检索结果也才能直接喂给攻击画像。

设计上的一条约束：日志字段要服务检索，不只是存储。

## 攻击样本库与检索字段

| 字段 | 含义 |
| --- | --- |
| `ip` | 攻击 IP |
| `url` | 请求 URL |
| `body` | 请求体 |
| `country` | 攻击国家 |
| `product` | 产品名称 |
| `header.<key>` | 请求头 |
| `attack_location` | 攻击位置，例如 URL path、body、headers、cookie、user_agent 等 |
| `attack_payload` | 攻击载荷 |
| `attack_type` | 攻击类别，例如 SQLi、XSS、SSRF、RCE、反序列化、文件读取等 |
| `method` | 请求方法 |
| `exposure` | 路径曝光度 |
| `url_match` | URL 匹配程度 |

## 检索能力

- 攻击流量实时入库。
- 攻击上下文日志。
- Header/Body/URL/Method 字段检索。
- 攻击载荷检索。
- 攻击位置检索。
- 攻击类型检索。
- 产品名称检索。
- 攻击 IP 检索。
- 国家/地区检索。
- 搜索历史。
- 检索 DSL。

## 检索之外的统计入口

参考平台的公开前端上还可以看到这些统计类入口：

- 首页实时攻击监控
- 情报检索统计
- 攻击国家统计
- 攻击 IP 统计
- 攻击产品统计
- 攻击类型统计
- 产品列表
- DSL 检索日志

## 安全边界

- 攻击位置、攻击类型、产品名称这类语义字段来自载荷分析，存在误判和漏判，检索结果需要人工复核。
- 检索命中的 IOC 不能直接全部封禁。
- 检索结果可能包含请求体原文，访问受日志和样本的访问控制约束。
