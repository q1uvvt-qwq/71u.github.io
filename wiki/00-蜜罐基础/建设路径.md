## 一句话概括

建设路线按"传统蜜罐基础能力 + 漏洞专项蜜罐专项能力"双线推进，先立仿真蜜罐的安全底线，再按 Profile 化框架堆可复用的漏洞仿真能力，不走照搬某个现成项目的路子。

## 为什么不直接照搬单个项目

| 项目/类型 | 代表 | 可借鉴点 | 不足 |
| --- | --- | --- | --- |
| 单 CVE 专项蜜罐 | Log4Pot、ToolShell-Honeypot | 能快速针对一个漏洞捕获请求 | 通常只服务单个漏洞，复用性弱 |
| Web 蜜罐框架 | SNARE/TANNER | 传感器和分析响应器分离，适合 Web 诱捕 | 需要按目标场景二次定制 |
| 通用 HTTP 仿真蜜罐 | Datadog HASH | 用配置描述 HTTP 软件和响应逻辑 | 更偏通用 HTTP 仿真，需要补 IOC 和漏洞语义分析 |
| 传统多协议蜜罐 | OpenCanary、Cowrie、Dionaea、T-Pot | 日志、诱捕、平台化经验成熟 | 无法直接模拟新曝 Web 漏洞细节 |

因此，最佳方案不是选一个项目直接完事，而是吸收它们的设计思路：

- 借鉴 Log4Pot：针对具体 CVE 快速捕获攻击请求。
- 借鉴 SNARE/TANNER：将传感器、分析器、响应策略拆开。
- 借鉴 HASH：用 YAML/JSON Profile 配置服务指纹和 HTTP 响应。
- 借鉴 T-Pot：后续做集中日志和可视化展示。
- 借鉴 Cowrie：记录会话、命令、下载链，并将攻击行为阶段化。

## 方案形态：CVE Profile 驱动的框架

最佳方案是建设一个 CVE Profile 驱动的 Web 漏洞专项蜜罐框架：

1. 每个漏洞用一个 Profile 描述服务指纹、路由、请求特征、响应策略和 IOC 提取规则。
2. 蜜罐核心服务只负责监听、仿真响应、记录请求和调用解析器。
3. 不运行真实漏洞组件，不执行攻击者命令，不允许任意出网。
4. 日志统一输出为 JSONL，后续可接入 SIEM、Elasticsearch、Loki、Kafka 或对象存储。
5. 分析器从请求中提取 IP、域名、URL、命令片段、Base64、文件名、Hash、User-Agent 等 IOC 候选。
6. 最终输出检测规则样例，例如 Sigma、Suricata、WAF 规则、Nuclei 检测思路。

这条路线可以复用到 Next.js / React RSC RCE、Log4Shell、Confluence RCE、Spring4Shell、SharePoint ToolShell 等不同漏洞。

## 平台总体架构

```text
攻击者/扫描器
    |
    v
公网/内网诱捕入口
    |
    v
Web 漏洞专项蜜罐 Sensor
    |
    +--> Profile 匹配器
    |       - 根据 Host、Path、Header、Body、Method 匹配漏洞 Profile
    |
    +--> 仿真响应器
    |       - 返回预设状态码、Header、错误信息、框架指纹
    |       - 不执行命令，不触发真实漏洞
    |
    +--> 请求日志器
    |       - 记录完整 HTTP 请求、连接信息、时间、会话
    |
    +--> Payload 分析器
    |       - 提取 URL、IP、域名、Base64、命令片段、文件名
    |
    +--> IOC 归一化器
    |       - 去重、打标签、计算置信度
    |
    v
JSONL 日志 / 队列 / SIEM / 数据库
    |
    v
分析报告 / IOC / 检测规则 / 告警
```

最小原型可以先不做复杂队列，直接：

```text
FastAPI/Flask/Node.js HTTP 服务
  -> YAML Profile
  -> JSONL 日志
  -> Python 分析脚本
  -> Markdown 分析报告
```

## 安全底线

注意：本阶段不建议直接暴露真实漏洞。更稳妥的方式是构建仿真蜜罐，模拟攻击者期望看到的服务特征和响应，但不执行攻击者提交的命令，不加载真实脆弱组件，不允许任意出网。

## 建设步骤

短期优先：

1. 选 OpenCanary 或 Cowrie 做传统蜜罐入门验证。
2. 建立统一日志字段模型。
3. 开始整理 Next.js / React RSC RCE、Log4Shell、Confluence RCE 的专项蜜罐仿真要点。
4. 后续实现一个不执行真实 Payload 的 Web 漏洞专项蜜罐 Demo。
