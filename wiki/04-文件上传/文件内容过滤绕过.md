## 一句话概括

后端不查后缀、也不查 MIME，而是**读文件正文、找里面有没有 `php` 这类关键字**时，可以用**大小写混淆**（把开标签写成 `<?PHP`）、**短标签**（`<?=`）等方式，让正文"看上去不含被禁字符串"，却依然能被 PHP 解释器执行。

## 本题情景与解题手法

### 题目形态

上传链路与上一题（web153）**一模一样** —— 后缀白名单仍然卡着，木马依然靠 `.user.ini` 被包含执行。原笔记：

> 和上一次一模一样，只在文件内容上添加了对 php 的过滤。

也就是说，**新增的防线只有一条：检查文件正文里有没有 `php` 关键字**。

服务端回显同一串 JSON：

```json
{"code":2,"msg":"\u6587\u4ef6\u7c7b\u578b\u4e0d\u5408\u89c4"}
```

### 第一步：先看懂回显里的 Unicode 转义

`\uXXXX` 是 **Unicode 转义序列**（JSON 里非 ASCII 字符的默认写法）。逐字拆开：

| 转义 | 字符 | 转义 | 字符 |
|---|---|---|---|
| `\u6587` | 文 | `\u4e0d` | 不 |
| `\u4ef6` | 件 | `\u5408` | 合 |
| `\u7c7b` | 类 | `\u89c4` | 规 |
| `\u578b` | 型 | | |

合起来就是「**文件类型不合规**」。

几种常见编码的对照（便于识别回显）：

| 编码类型 | 示例 | 出现场景 |
|---|---|---|
| Unicode 转义 | `\u6587\u4ef6` | JSON 响应里的中文（本题） |
| URL 编码 | `%E6%96%87%E4%BB%B6` | 浏览器地址栏 / GET 参数 |
| HTML 实体 | `&#25991;&#20214;` | HTML 页面 |
| Base64 | `5paH5Lu2` | 二进制数据传输 |

### 第二步：定位过滤点在"内容"而不是"类型"

前面的题卡的是后缀、MIME，这题这些都能过 —— 说明过滤发生在**文件正文**上：后端读了图片马的内容，发现里面有 `php`，于是拒绝。

### 第三步：把开标签里的 `P` 大写，绕过内容过滤

原来的木马正文（下面用 `<木马>` 代指正文里的命令执行代码）：

```text
<?php <木马>
```

把它改成大写开标签：

```text
<?PHP <木马>
```

原笔记的解法一句话：

> 将 `P` 大写绕过即可。

**PHP 的开标签是大小写不敏感的**：`<?php`、`<?PHP`、`<?Php` 完全等价，解释器照常执行；而后端若用**区分大小写**的方式找 `php` 这个字符串，`<?PHP` 里就没有连续的小写 `php`，于是放行。

### 第四步：访问执行，直接 GET 拿 flag

原笔记提示不必上蚁剑，直接发请求即可：

```http
GET /upload/?cmd=system('tac ../flag.php'); HTTP/1.1
Host: 靶机地址
```

> `upload/` 是目录，请求它会落到该目录的 `index.php`；`index.php` 执行时被 `.user.ini` 自动包含进我们的图片马，`cmd` 参数即被正文里的代码执行 —— 这正是上一题（web153）留下的链子，详见 04 篇。

URL 编码后就是原笔记写的形式：

```text
/upload/?cmd=system(%27tac%20../flag.php%27);
```

### 第五步：web155 —— 大小写不管用了

原笔记继续记了一句：

> web155 过滤的还是 php 但是不区分大小写。

也就是说过滤规则从 `/php/` 变成了 `/php/i`（或 `stripos`），`<?PHP` 这种大小写混淆**不再有效**。这时候需要换思路（短标签等，见原理第 3 节）。

### 上传手法一句话总结

> 上层链路不变（`.user.ini` 包含图片马）→ 后端新增"正文含 `php` 就拒"的检查 → 把开标签写成 `<?PHP`，让正文不含小写 `php` → 图片马上传成功 → 访问 `/upload/?cmd=system('tac ../flag.php')` 读 flag。web155 换成不区分大小写过滤后，大小写招数失效。

## 原理

### 1. PHP 开标签为什么大小写不敏感

PHP 的词法分析器在识别开标签时，**不区分字母大小写**。所以下面三种写法对解释器完全等价：

```text
<?php        <?PHP        <?Php
```

但要注意：**标签内部的关键字是否敏感，是另一回事** —— 函数名、关键字（`echo`）本身大小写不敏感，而**字符串字面量、变量名是敏感的**。本题利用的是"标签"这一层。

由此得到一条通用规律：**过滤规则与解释器对同一段文本的"读法"不一致，就能绕过**。

| 文章 | 过滤方的读法 | 解释器的读法 | 差距 |
|---|---|---|---|
| 本题 | 按小写找 `php`（区分大小写） | 开标签大小写不敏感 | `<?PHP` 过 |
| 魔术字节 | 看文件开头几个字节 | 从 `<?` 开始找标签 | 前面垫 `GIF89a` |
| 后缀黑名单 | 比较整个扩展名字符串 | 服务器按后缀映射解释器 | `.php5` / `.Php` |
| 双扩展名 | 只看某一个点后的后缀 | 服务器看另一个后缀 | `e.jpg.php` |

### 2. 常见"内容过滤"实现与对应绕过

不同实现对应不同绕法，先判断过滤是**拒绝**还是**删除**：

| 过滤实现 | 逻辑 | 绕过思路 |
|---|---|---|
| 按小写找 `php`，命中即拒绝（区分大小写） | 拒绝式 | 大小写混淆 `<?PHP` |
| 不区分大小写找 `php`，命中即拒绝 | 拒绝式 | 短标签 `<?=`、`<?`（不含 `php`） |
| 把正文里的 `php` 删掉后保存 | 删除式 | 写成 `<?phpphp`，删完剩 `<?php` |
| 正则匹配整段开标签 | 拒绝式 | 短标签 `<?=`；或把标签拆开（受限） |
| 关键字黑名单（`eval`/`system` 等） | 拒绝式 | 换函数 / 拼接函数名 |

> **关键判断**：响应是"被拒"还是"文件内容被改"。前者是拦截，用"写得不触发规则"绕过；后者是净化，用"删除后拼回原样"绕过。本题是前者。

### 3. web155：过滤不区分大小写时怎么办

原笔记只记录了现象，没写解法。按通用思路可以试**短标签**：

```text
<?= <命令执行代码> ?>
```

`<?=` 是"短回显标签"，**自 PHP 5.4 起始终可用**（不受 `short_open_tag` 影响），且文本里没有 `php` 序列。若题目连 `=` 也过滤，则要考虑换别的函数名或拆分关键字等更复杂的手法。

> 此段属于**通用知识补充**：原笔记在 web155 处只写了"过滤不区分大小写"，未给出实际 payload，此处仅提供候选方向，不代表已在该题验证。

### 4. 为什么访问 `/upload/` 就能执行木马

这是承接 04 篇的机制：

1. `/upload/` 是目录，Web 服务器默认用该目录下的 `index.php` 处理；
2. `index.php` 触发 PHP 解释器启动；
3. 解释器读到同目录的 `.user.ini`（`auto_prepend_file=e.png`），**在执行 `index.php` 前先包含 `e.png`**；
4. `e.png` 里的 PHP 正文被执行，超全局变量拿到 URL 里的 `cmd`。

所以木马文件后缀是 `.png`、正文又"不含小写 php"，两道防线同时绕过。

## 利用条件

1. **上传链路可用**（本题沿用 03/04 的 `.user.ini` 方案，或后端本身允许 `.php` 落地）
2. **被绕过的只是"内容关键字"这一层**：过滤实现与 PHP 解释器对文本的读法存在差异
3. **能访问到能执行 PHP 的入口**（`index.php`、木马本身等）
4. 过滤是**拒绝式**而非删除式（删除式要改成"拼回原样"的 payload）

## Payload 速查

| 过滤规则 | 绕过写法 | 说明 |
|---|---|---|
| 区分大小写找 `php` | 开标签写成 `<?PHP` | 本题 |
| 不区分大小写找 `php` | 短标签 `<?=` | 不含 `php` 序列 |
| 删除式（删掉 `php` 后保存） | 写成 `<?phpphp` | 删掉一次后拼回 `<?php` |
| 禁 `eval` 等函数名 | 换 `assert` / `system`，或拼接函数名 | 视环境而定 |
| 匹配整段开标签 | 短标签 `<?=` | 避开整个标签特征 |

## 完整示例

图片马（注意开标签大写，正文同 04 篇的一句话木马）：

```text
<?PHP <一句话木马正文>
```

其余步骤（`.user.ini` + 上传 + 访问）与 04 篇一致。执行命令：

```http
GET /upload/?cmd=system('tac ../flag.php'); HTTP/1.1
Host: 靶机地址
```

等价的可直接粘贴形式：

```text
/upload/?cmd=system(%27tac%20../flag.php%27);
```

## 踩坑与备注

- **先解码回显再判断**：`\u6587\u4ef6\u7c7b\u578b\u4e0d\u5408\u89c4` 就是「文件类型不合规」，别被转义串唬住。
- **"大小写绕过"只对区分大小写的过滤有效**：web154 管用、web155 就不管用。判断依据是回显 —— 同一个 payload 在两道题上结果不同，就说明过滤强度变了。
- **原笔记在 web155 只留了现象**，没有给最终 payload；本文对 web155 的处理是明确标注的"通用方向"，未杜撰已验证解法。
- **访问入口写成 `/upload/` 即可**：目录会落到 `index.php`，木马经 `.user.ini` 被包含；不必直连 `e.png`（它不会被执行，原因见 04 篇）。
- **内容过滤常与后缀/MIME 过滤叠加**：本题只加了内容一层，所以只处理这一层。实战中要按"哪一层被拒"逐层拆解，而不是看到一个 payload 不行就乱换。
- 完整的可执行木马写法见 04 篇；本篇聚焦"正文关键字被过滤"这一层，正文用占位符表示，避免与 04 篇重复整段木马代码。
