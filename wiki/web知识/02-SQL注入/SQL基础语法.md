## 一句话概括

SQL 是用于管理和操作"关系型数据库"的标准计算机语言，功能围绕 CRUD 四个核心动作展开；其中 SELECT（读）是最重要的命令，也是注入 payload 最常寄生的地方。

## 原理

### 1. 名字的含义

Structured（结构化）+ Query（查询）+ Language（语言）= 结构化查询语言，专门用来与结构化的数据打交道。

### 2. 什么是数据库

把数据库想象成一个高度组织化的电子文件柜，柜子里有很多张表格（称为表），比如：

- 一张用户表：存放所有用户信息（ID、姓名、电话……）
- 一张订单表：存放所有订单记录（订单号、用户ID、商品、金额……）
- 一张产品表：存放所有产品信息（产品ID、名称、价格……）

这些表格之间可以通过共同的字段（如"用户ID"）相互关联，所以被称为关系型数据库。"关系"指的就是表与表之间的这种关联。

### 3. SQL 能做什么：CRUD

| 动作 | 含义 | 关键字 |
|---|---|---|
| C - CREATE（创建） | 创建新的数据库、表；向表中插入新的数据行 | `CREATE`、`INSERT` |
| R - READ（读取） | 从表中查询、检索数据；可以过滤、排序、分组，并同时从多张表获取关联信息 | `SELECT`（最重要的 SQL 命令） |
| U - UPDATE（更新） | 修改表中已有的数据 | `UPDATE` |
| D - DELETE（删除） | 从表中删除数据行 | `DELETE` |

### 4. 一条 SELECT 的骨架

对注入而言，最需要刻进脑子的是这条骨架：

```sql
SELECT <列名, ...> FROM <表名> WHERE <布尔表达式>;
```

- `SELECT` 后面写要拿哪些列，`*` 表示全部列；
- `FROM` 后面写从哪张表拿；
- `WHERE` 后面写只拿满足什么条件的行。

注入点几乎总是落在 `WHERE` 后面的表达式里，因为那里正是开发者写的固定逻辑与拼接进来的用户输入交界的地方。这也是为什么 `MySQL核心原理` 里会强调一句"`WHERE` 后面只能接布尔表达式"，它决定了你能往注入点里塞什么形状的东西。

## 利用条件

SQL 语法本身不是漏洞，但对注入来说，需要先记住这几件事才能构造出合法 payload：

- 知道当前语句的上下文位置：注入点落在 `WHERE` 里、落在 `ORDER BY` 后、还是落在 `LIMIT` 后，可用的语法完全不同；
- 知道 `WHERE` 后面要接布尔表达式：所以要写 `1=1`、`or 1=1`、`and ascii(...)>100` 这类能算出真假的表达式，而不是随便丢一段字符串；
- 知道 SQL 关键字大小写不敏感：`select` 与 `SELECT` 等价，这既是书写惯例的由来，也是绕大小写敏感黑名单的抓手；
- 知道注释符：`-- `、`#` 用来截断后面的固定 SQL，把结构改造成自己想要的样子。

## Payload 速查

| 目的 | 语句 |
|---|---|
| 查全部 | `SELECT * FROM 表名;` |
| 条件查询 | `SELECT 列1, 列2 FROM 表名 WHERE 列 = '值';` |
| 插入 | `INSERT INTO 表名 (列1, 列2) VALUES ('值1', '值2');` |
| 更新 | `UPDATE 表名 SET 列 = 新值 WHERE 列 = '值';` |
| 删除 | `DELETE FROM 表名 WHERE 列 = '值';` |
| 排序（常用于猜列数） | `SELECT * FROM 表名 ORDER BY 1;` |
| 注释掉后续 SQL | `-- `（MySQL 需带一个空白）、`#` |

## 完整示例

假设有一张 `员工表`：

| ID | 姓名 | 部门 | 工资 |
| :--- | :--- | :----- | :--- |
| 1 | 张三 | 技术部 | 8000 |
| 2 | 李四 | 销售部 | 7000 |
| 3 | 王五 | 技术部 | 9000 |

1. 查询（READ）

```sql
-- 查找所有员工的所有信息
SELECT * FROM 员工表;

-- 只查找技术部的员工姓名和工资
SELECT 姓名, 工资 FROM 员工表 WHERE 部门 = '技术部';
```

结果：

| 姓名 | 工资 |
| :--- | :--- |
| 张三 | 8000 |
| 王五 | 9000 |

2. 插入（CREATE）

```sql
-- 新来一位员工"赵六"
INSERT INTO 员工表 (姓名, 部门, 工资) VALUES ('赵六', '市场部', 6000);
```

3. 更新（UPDATE）

```sql
-- 给张三涨工资
UPDATE 员工表 SET 工资 = 8500 WHERE 姓名 = '张三';
```

4. 删除（DELETE）

```sql
-- 李四离职了，删除他的记录
DELETE FROM 员工表 WHERE 姓名 = '李四';
```

## 注意事项

- `WHERE 部门 = '技术部'` 里的引号很关键：字符串类型的值必须用引号包起来。这也正是注入的着力点，`MySQL核心原理` 会说明数字型与字符型注入点的区别，关键就是这个引号在不在。
- 表名与列名写成中文只是为了可读性，真实环境里它们一般是英文标识符，注入时必须原样写对，写错会直接语法报错。
