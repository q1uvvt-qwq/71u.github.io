## 一句话概括

**把 PHP `mt_rand()` 产生的随机数，反推回当时 `mt_srand()` 播种用的种子值。** 一旦拿到种子，之后所有的随机数就全部可预测 —— 需要「随机 token」的校验就形同虚设。

## 原理

- PHP 有个随机数函数 `mt_rand()`，它其实是「伪随机」——**只要你知道最初播的种子，就能算出之后所有随机数**；
- `php_mt_seed` 是反着来的工具：**你给我一个（或多个）随机数，我帮你还原出那个种子**；
- 拿到种子 = 你的随机数就全透明了，能预测所有后续输出。

### 为什么「伪」随机可以被反推

```text
mt_srand(种子)         ← 播一次种
      │
      ▼
  MT 算法（梅森旋转）   ← 确定性算法：同样的种子，永远产出同样的序列
      │
      ▼
mt_rand() → R1, R2, R3, ...
```

关键在于这是个**确定性算法**：

- 算法是公开的，唯一的未知量只有「种子」；
- 种子通常是 32 位整数，取值范围只有 2³² ≈ 43 亿；
- 给你一个 `mt_rand()` 的输出，就能**穷举所有可能的种子**，看哪个能重现这个输出。

> **为什么只给第一个输出就够**：43 亿听起来很多，但 `php_mt_seed` 是高度优化过的暴力搜索，在当前 CPU 上「单个输出反推种子」只需要几十秒到几分钟。给多个输出只是为了让候选种子更唯一、搜索更快。**信息给得越多，搜索空间越小。**

## 利用条件

1. **能拿到至少一个 `mt_rand()` 的输出**：题目泄露、或者你能从其它接口推出来；
2. **知道输出的取值范围**（可选但很有用）：如果知道「结果在 0~999 之间」，搜索会快很多；
3. **知道 PHP 版本**：种子格式在 PHP 7.1 前后有变化，工具会**输出多个候选**，需要按版本挑；
4. **目标后续的随机数生成逻辑可复现**：你得能写出和目标一样的 `mt_rand()` 调用序列。

## 常用指令（调用模式）

### 1. 最简单模式：给一个随机数（第 1 个）

```bash
./php_mt_seed 随机数值
```

最常用。给第一个 `mt_rand()` 输出，找出种子。

### 2. 精确匹配指定格式（带上下限）

可以告诉它：这个随机数的取值范围（比如已知是 0~某个数，或多个随机数）。

单个值指定范围：

```bash
./php_mt_seed 最小值 最大值
```

例：已知第一次 `mt_rand()` 结果在 0~999 之间

```bash
./php_mt_seed 0 999
```

多个值指定范围：

```bash
./php_mt_seed 值1取值范围 值2取值范围 ...
```

例：三次取值分别在 `[0,99]` `[0,99]` `[0,65535]`

```bash
./php_mt_seed 0 99 0 99 0 65535
```

> **每两组数 = 一次 `mt_rand()` 的「最小值/最大值」区间。**

### 3. 六边形高级模式（第三个值不确定时）

有些 `mt_rand()` 的结果不是单纯整数，`php_mt_seed` 的六边形模式可以处理。一般做题用不到，了解即可：

```bash
./php_mt_seed H
```

具体用法查官方文档。

## 本题情景与解题手法

### 题目形态

靶机提供一个 `?r=` 参数，返回一个随机数；同时校验 `Cookie: token=<某值>`。典型形态是：

```text
http://靶机地址/?r=0     → 1553861231        （泄露第一次 mt_rand() 的值）
提交时需要带上 Cookie: token=<算出来的值>
```

题目源码（本质）：

```php
<?php
mt_srand((int)($_GET['seed'] ?? time()));   // 内部用某个种子播种
$first = mt_rand();
if (isset($_GET['r'])) {
    echo $first;                            // 泄露第一次结果
    exit;
}
// 校验阶段用的是后续的随机数
if ($_COOKIE['token'] === (string)(mt_rand() + mt_rand())) {
    echo $flag;
}
```

### 第一步：确认泄露的是第一次 `mt_rand()` 的值

请求 `?r=0`，看返回的数字。如果这个数字就是源码里那个 `echo mt_rand()`，那么**它就是第一个输出**。

> **怎么判断是不是第一次**：把 `?r` 的取值换几次，看返回是否**每次变**（可能每次请求都重新播种）、还是**固定不变**（服务端只播一次种）。如果每次请求都变，说明每次请求都会 `mt_srand(time())`，那泄露的只是「这次连接」的种子，用处有限。

### 第二步：用 php_mt_seed 反推种子

```bash
./php_mt_seed 1553861231
```

输出（示例）：

```text
seed = 1003376876 (PHP 7.1.0+)
...
```

> **为什么输出多行**：不同 PHP 版本的种子处理方式不同，工具会把所有可能都列出来。形如 `(PHP 7.1.0+)` 的标注告诉你这行对应哪个版本的 PHP。

### 第三步：确认靶机 PHP 版本，选中对应种子

用 `phpinfo()` 页面、报错信息、`Server`/`X-Powered-By` 头，或直接用 `?r=` 的返回值形态来判断版本。**从输出里挑标注与你目标版本匹配的那一行。**

### 第四步：本地复现，算出目标值

写一个 PHP 脚本，把种子和调用序列**完全照抄**题目源码：

```php
<?php
mt_srand(1003376876);
mt_rand();                      // 跳过第一次（题目泄露的那次）
$token = mt_rand() + mt_rand(); // 复现校验用的值
echo $token;
```

### 第五步：提交

```bash
# 拿到 ?r=1553861231 之后
curl "http://靶机地址/?r=1553861231" \
     -H "Cookie: token=算出的值"
```

→ 返回 flag。

### 解题手法一句话总结

> **找到泄露 `mt_rand()` 输出的接口** → 用 `./php_mt_seed <第一个输出>` 反推种子 → 按 PHP 版本挑种子 → **本地写出与题目一致的 `mt_srand/mt_rand` 调用序列**算出后续值 → 提交带 Cookie 的请求拿 flag。

## 踩坑与备注

- **种子格式随 PHP 版本变化**：PHP 7.1.0 前后算法实现有差异，工具会**同时输出多个候选**，一定要挑标注版本匹配的那一行，挑错就算不出来。
- **「一次输出」往往不足以唯一定位种子**：可能得到多个候选，这时需要**多拿几个输出**（用 `取值范围` 形式的多次输入）来收敛。
- **必须精确复现调用次数**：题目里如果先 `mt_rand()` 了一次再用结果、或者调用顺序和你写的不一样，算出来的 token 一定不对。**照着源码一行行抄**是最稳的。
- **`-march=native` 会针对你本机 CPU 优化**，换机器跑同一份二进制可能出问题，需要重新编译。
- **PHP 8 之后 `mt_rand` 的实现仍是 MT19937**，`php_mt_seed` 依然适用；但若题目用的是 `random_int()` / `random_bytes()` 这类**密码学安全**随机数，本工具完全无效 —— 那不是伪随机，推不出来。
