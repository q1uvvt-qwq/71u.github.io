## 以太坊、ETH和智能合约

### 以太坊

**以太坊（Ethereum）是一个由许多节点共同维护的区块链网络。\**除了记录资产转账，它还能运行部署在区块链上的程序，这类程序称为\**智能合约**。

可以把以太坊理解为一个公共的链上计算平台：

- 节点共同保存数据；
- 用户通过交易提交操作；
- 智能合约按照代码处理操作；
- 所有节点按照相同规则验证结果；
- 结果被记录在区块链上。
- 

### ETH

**定义**：以太坊的原生资产

ETH主要有三种用途：

1. **转账和保存价值**
   用户可以把ETH发送给其他地址。
2. **支付交易手续费**
   在以太坊上转账、调用智能合约或部署智能合约，都可能需要支付手续费。手续费以ETH结算。
3. **参与网络验证**
   以太坊使用权益证明机制。验证者需要质押ETH，并参与区块提议和验证。

以太坊上的USDT、USDC等代币不是ETH。它们通常由智能合约创建和管理，但交易这些代币仍然需要使用ETH支付手续费。



### 智能合约

**定义**：智能合约是一段部署在区块链上的程序。

它可以：

- 记录代币余额；
- 处理代币交换；
- 管理借贷和抵押；
- 保存数字藏品；
- 按照条件分配资金；
- 管理应用的权限和规则。

用户与智能合约交互时，会发送一笔交易。交易中可以包含“调用哪个功能”和“使用哪些参数”等数据。



### 以太坊、ETH和智能合约的区别

| 概念         | 含义                                   |
| ------------ | -------------------------------------- |
| **以太坊**   | 整个区块链网络和运行规则               |
| **ETH**      | 以太坊的原生资产                       |
| **智能合约** | 部署在以太坊上、按照代码自动执行的程序 |



### 以太坊交易类型

常见交易可以分为三类：

| 类型             | 作用                             |
| ---------------- | -------------------------------- |
| **ETH转账**      | 把ETH从一个地址发送到另一个地址  |
| **调用智能合约** | 执行转币、兑换、借贷或授权等操作 |
| **部署智能合约** | 把新的程序发布到以太坊上         |

因此，看到“交易金额为0 ETH”并不代表这笔交易什么都没做。它可能携带了合约调用数据，例如批准某个合约使用代币。



### 运行者

以太坊没有一台负责所有工作的中央服务器。网络主要由以下参与者组成：

- **用户**：通过钱包发起交易；
- **节点**：接收、传播和检查交易与区块；
- **验证者**：参与提出和确认区块；
- **开发者**：创建智能合约和应用；
- **智能合约**：根据收到的交易执行代码。

节点按照相同协议检查结果。违反规则的交易或区块不会被正常节点接受。



### 以太坊和钱包关系

钱包是用户访问以太坊的工具，它可以：

- 管理账户；
- 查看链上余额；
- 构造交易；
- 请求用户签名；
- 把签名后的交易发送到网络。

**钱包不是以太坊，资产也不是存放在钱包软件里。**资产归属记录保存在区块链上，钱包主要管理能够控制地址的密钥。



### 学习区块链安全时经常使用以太坊

以太坊不仅涉及转账，还涉及智能合约、代币、交易所、借贷、预言机和跨链桥。因此，区块链安全中的很多典型问题都可以在以太坊生态中观察到，例如：

- 私钥泄露；
- 恶意签名和代币授权；
- 智能合约漏洞；
- 权限配置错误；
- 价格操纵；
- 交易抢跑；
- 跨链桥攻击。

**一句话概括：以太坊是一个能够共同维护账本并运行智能合约的区块链网络，ETH是它的原生资产。**
