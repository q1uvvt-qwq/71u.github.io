## 私钥、公钥、地址、钱包与助记词

本章解决区块链安全中最重要的问题：

> 区块链怎样判断谁有权使用某笔资产？

区块链通常不会核对姓名或身份证，而是检查交易是否满足资产的控制条件。最常见的控制方式，是提供由正确私钥生成的数字签名。

### 五个概念的关系

```
随机生成私钥
      ↓
通过密码学计算得到公钥
      ↓
根据公钥或脚本生成地址
      ↓
地址接收链上资产

私钥 + 交易内容
      ↓
生成数字签名
      ↓
网络使用公钥验证签名
```

钱包负责管理这些密钥、地址和交易。助记词通常用于恢复一组由钱包生成的密钥。



### 私钥

**私钥是一个随机生成的巨大数字，用于授权链上操作。**

私钥最重要的作用是对交易进行签名。拥有私钥的一方通常可以使用相应地址控制的资产。

私钥必须具有足够的随机性。比特币和以太坊常见私钥的长度为256位，可用组合数量极其庞大。只要生成过程安全，通过暴力尝试猜中某个私钥在现实中不可行。

私钥不需要发送给区块链。正常签名过程是：

```
私钥保留在钱包中
      ↓
钱包对交易内容签名
      ↓
只把交易和签名发送给网络
```

网络需要验证签名，不需要知道私钥本身。



### 公钥

**公钥由私钥通过单向密码学运算得到，用于验证数字签名。**

关系可以表示为：

```
私钥 → 公钥
```

从私钥计算公钥比较容易，但从公钥反推出私钥在现有计算能力下极其困难。

公钥主要用于：

- 验证交易签名；
- 证明签名者掌握对应私钥；
- 进一步生成区块链地址。

公钥公开通常不会直接导致私钥泄露，但重复使用地址和公钥可能增加隐私关联。



### 地址

**地址是区块链上用于接收资产或标识账户、脚本、合约的字符串。**

地址通常由公钥或脚本经过哈希和编码生成。不同区块链的地址格式不同：

| 网络     | 地址特点                                   |
| -------- | ------------------------------------------ |
| 比特币   | 地址可能代表公钥哈希、脚本或其他花费条件   |
| 以太坊   | 普通账户地址通常由公钥计算得到，以`0x`开头 |
| 智能合约 | 合约也有地址，但通常没有对应的用户私钥     |

地址可以公开，用于接收资产和查询链上记录。但公开地址也会暴露与该地址相关的交易活动。

地址不是密码。别人知道地址后，一般只能向它发送资产、查询记录或尝试与它交互，不能因此直接转走其中的资产。



### 钱包

**钱包是管理密钥、地址和交易的工具。**钱包本身通常不保存真正的链上资产。

钱包主要完成：

- 生成和保存私钥；
- 根据私钥生成公钥与地址；
- 查询链上余额；
- 构造交易；
- 请求用户确认；
- 使用私钥签名；
- 广播签名后的交易。

钱包界面显示的是从区块链或节点查询到的数据。资产归属仍然记录在区块链上。

#### 托管钱包与自托管钱包

| 类型           | 谁掌握私钥     | 资产操作方式                     |
| -------------- | -------------- | -------------------------------- |
| **自托管钱包** | 用户自己       | 用户直接签名并发送链上交易       |
| **托管钱包**   | 交易所或服务商 | 用户登录平台，由平台代为处理资产 |

自托管钱包中，助记词和私钥丢失通常没有中央机构可以恢复。

托管钱包中，用户可能通过平台的身份验证找回账户，但资产安全依赖平台的密钥管理、提现规则和经营状态。

因此，交易所账户里的“余额”往往先是平台内部记账；只有提现到自托管地址，才会产生相应的链上转移。

#### 热钱包与冷钱包

| 类型         | 特点                           | 主要风险                     |
| ------------ | ------------------------------ | ---------------------------- |
| **热钱包**   | 密钥所在设备经常联网，操作方便 | 恶意软件、钓鱼和设备入侵     |
| **冷钱包**   | 密钥尽量保持离线               | 备份丢失、物理损坏和操作错误 |
| **硬件钱包** | 在专用设备内保存密钥并完成签名 | 假设备、恶意授权、备份泄露   |

硬件钱包可以减少私钥被电脑直接读取的风险，但不能阻止用户确认恶意交易。最终仍需核对设备上显示的地址、金额和操作内容。



### 助记词

**助记词是一组便于人工备份的单词，通常用于恢复整个钱包的密钥体系。**

常见助记词由12个、18个或24个单词组成。钱包通过助记词生成种子，再按确定性规则生成多个私钥和地址：

```
助记词
  ↓
种子
  ↓
主密钥
  ↓
多个子私钥
  ↓
多个公钥和地址
```

因此，一组助记词可能控制多个地址、多个账户，甚至在不同兼容网络上派生出不同密钥。

助记词的权限通常比单个私钥更大：

| 泄露内容 | 可能影响                             |
| -------- | ------------------------------------ |
| 单个地址 | 通常只影响隐私，不直接获得控制权     |
| 单个私钥 | 可能控制该私钥对应的资产             |
| 助记词   | 可能恢复并控制整个钱包中的多个账户   |
| 钱包密码 | 影响取决于是否同时获得钱包文件或设备 |

#### 助记词与钱包密码的区别

钱包密码、PIN码和助记词作用不同：

| 内容           | 作用                       |
| -------------- | -------------------------- |
| **助记词**     | 恢复钱包及其密钥           |
| **私钥**       | 直接签署对应账户的交易     |
| **钱包密码**   | 解锁本地钱包或解密钱包文件 |
| **设备PIN码**  | 解锁手机或硬件钱包设备     |
| **交易所密码** | 登录由交易所管理的账户     |

修改钱包密码不会修改助记词，也不会自动生成新的链上账户。

攻击者如果已经获得助记词，即使不知道钱包密码，也可能在另一台设备上恢复钱包。仅修改原钱包的密码无法阻止这种控制。
