## 一句话概括
漏洞检测模板与规则生态是一批公开资产：Nuclei 的 YAML 模板、社区模板库、Suricata/IDS/WAF 规则，加上用配置文件描述 HTTP 软件的 Datadog HASH。它们不是蜜罐，是蜜罐 Profile 的输入源。

## 定位
定义：这一类资产描述的是如何验证一个漏洞，不是如何扮演受害目标。它们的价值在于把漏洞特征沉淀成可读、可复用的结构化文本，因此可以作为蜜罐要模拟的路径、Header 和响应的来源。

Nuclei 不是蜜罐，是 YAML 模板驱动的漏洞扫描器。它证明了漏洞检测逻辑可以 Profile/Template 化，并且有庞大的 CVE 模板生态。Datadog HASH 是 Datadog 开源的 HTTP Agnostic Software Honeypot，用于创建和运行低交互 HTTP/HTTPS 蜜罐。

## 能力清单

### ProjectDiscovery Nuclei
- YAML 模板描述请求、匹配器、提取器
- HTTP、DNS、Network、SSL、Code 等多协议支持
- 大量社区 CVE 模板
- 官方模板签名验证
- 支持自动更新公开模板
- 判断：CVE/Profile 生成明确支持漏洞检测模板，但不是蜜罐生成；高仿真 Web 指纹需要二次开发，可从模板中反向提取请求特征；HTTP 流量采集不适用，Nuclei 发起请求，不接收攻击流量；Payload/IOC 间接支持，模板有 extractor/matcher 思路；检测规则输出明确支持检测模板，但不是 WAF、Sigma 输出；安全隔离不适用
- 资料：<https://github.com/projectdiscovery/nuclei>

### Nuclei Templates
- 社区漏洞模板库，沉淀 CVE 请求特征和检测逻辑
- 模板数量大、更新快，漏洞路径和检测规则可读
- 不能直接转成高仿真蜜罐，需要语义转换
- 可吸收的是路径、Header、Matcher/Extractor 输入
- 资料：<https://github.com/projectdiscovery/nuclei-templates>

### Suricata/IDS/WAF 规则
- 网络和 Web 攻击检测规则，可直接沉淀检测逻辑
- 不是诱捕系统
- 用途是规则输出目标和特征参考

### Datadog HASH
- 用 YAML 配置 HTTP/HTTPS 蜜罐，模拟任意基于 HTTP 的软件
- 内置 honeytraps
- 支持随机化，降低被识别为蜜罐的风险
- 可与 Datadog 集成采集和分析日志、HTTP 请求
- 支持从 Swagger 生成 honeypot profile
- 判断：高仿真 Web 指纹明确支持 HTTP 软件模拟，HTTP 流量采集明确支持日志和 HTTP 请求采集，两项都是强相关能力；CVE/Profile 生成需要二次开发，它支持 HTTP profile，但不是 CVE 专项；Payload/IOC 分析需要二次开发；检测规则输出未发现支持；安全隔离间接支持，低交互、配置化，但安全部署需自行设计
- 资料：<https://github.com/DataDog/HASH>

## 局限
- Nuclei 是主动扫描，不是被动蜜罐，不模拟受害服务
- 模板描述如何验证漏洞，不描述如何扮演受害目标，没有仿真响应，也不采集真实攻击流量
- Extractor 是检测结果提取，不是蜜罐 IOC 管道
- HASH 缺少 CVE 情报输入、漏洞语义、Payload 解码、IOC 提取和规则输出闭环

## 素材中的不确定处
