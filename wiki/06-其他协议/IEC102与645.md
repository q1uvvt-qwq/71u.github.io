## 一句话概括

IEC 60870-5-102 和 DL/T 645 都和电能表有关，但分工不同：DL/T 645 负责"采集终端去问电能表要数据"（靠近表本体），IEC 60870-5-102 负责"采集终端/计量设备把电量数据送到上级系统"（靠近主站）。

## 原理

### 一条链路看分工

一块风电场关口电能表，数据流这样走（依据素材）：

```text
电能表
  ↓ DL/T 645
计量采集终端 / 电表网关
  ↓ IEC 60870-5-102
电能量采集系统 / 计量主站 / 历史库
```

记法：

```text
DL/T 645：电表 → 采集终端
IEC 102：采集终端 → 上级计量系统
```

两者都从属于电力计量业务，一个在"末端抄表"，一个在"上行送数"。

### IEC 60870-5-102 的定位

IEC 60870-5-102 是电力系统里专门偏"电能量计量数据采集"的规约，与 IEC 104 同属 IEC 60870-5 这一类电力远动标准，但侧重点不同。

它管的是电量统计问题，不涉及控制设备：

```text
这块电表累计走了多少电？
这个风电场今天送了多少电？
这个关口表本月累计上网多少电？
尖、峰、平、谷各是多少电量？
```

### DL/T 645 的定位

DL/T 645 是国内电能表最常见的一种"抄表通信规约"：

```text
计量采集终端 / 抄表系统
        ↓ DL/T 645
电能表
```

定义：两种规约都只做计量读取，不控制风机、PLC、断路器。

### 靶场中的计量链路还原

在风电攻击链里，电量数据不出现在控制链路上，只出现在报表/结算侧。理解它的价值在于：

```text
1. 明确"电量"是统计量，不是过程量，控制指令影响不到它。
2. 明确"电量"的可信度依赖采集链路完整：电能表 -> 采集终端 -> 计量主站。
3. 一旦中间任一环被篡改，报表与结算就会失真。
```

## 报文/字段对照

### 分工与对比表

| 维度 | DL/T 645 | IEC 60870-5-102 |
|---|---|---|
| 业务定位 | 采集终端 → 电能表 抄表 | 采集终端 → 上级计量系统 送数 |
| 靠近哪一端 | 电表本体（末端） | 主站系统（上行） |
| 主要数据 | 电量、电参量、表计状态 | 电量数据上送、计量采集 |
| 是否管控制 | 否，只管计量读取 | 否，偏计量数据采集 |
| 与 IEC 104 的关系 | 不同体系 | 同属 IEC 60870-5 家族 |

### 典型数据对象

DL/T 645 读取的典型数据（依据素材）：

```text
电压
电流
有功功率
无功功率
正向有功总电量
反向有功总电量
尖峰平谷电量
表计时间
表计状态
告警状态
```

其中与"结算"直接相关的是电量类：

```text
正向有功总电量   上网/用电方向的累计电量
反向有功总电量   反送方向的累计电量
尖峰平谷电量     按费率时段分段的电量
```

## 安全视角

### 为什么电量被篡改比"读不到"更严重

读不到是可用性问题，会立刻暴露、立刻被处理；电量被篡改是数据可信问题，常常长期不被发现：

```text
1. 结算是按电量算钱的：电量偏差直接对应经济利益。
2. 考核按电量算指标：上网电量、利用小时数受影响。
3. 报表按电量做统计：历史趋势、月报年报全部失真。
4. 篡改可以做得"合理"：数值落在正常范围、变化平滑，不触发明显告警。
```

对应到靶场里演示的四类数据攻击，电量属于最"隐蔽"的一类：

```text
伪造  改值（SOURCE_OVERRIDE / RANGE / RATE）
删除  断档（NO_DATA）
延迟  过期重放（STALE）
校验  签名不符（HMAC_MISMATCH）
```

### 靶场类比：平原链的发电量寄存器

平原链中用于演示"数据完整性校验"的发电量寄存器，是电量类数据的一个简化模型：

```text
HR97/98 组成 32 位发电量，单位 0.01kWh
例：目标 1000.00 kWh = 100000 = 0x000186A0
    高字 HR98=1，低字 HR97=0x86A0=34464
```

注意：电量在设备侧通常是多寄存器拼接的 32 位量，读写时要按大小端和高低字对齐，否则会出现数量级错误。

### 防护落点

- 完整性保护：对关键电量做 HMAC-SHA256 签名，随数据上送，接收端验签；签名不符即判定被改动。
- 时间戳与新鲜度：每条数据带产生端时间戳，接收端设最大允许时延，超龄判 STALE，防御重放。
- 范围与跳变校验：电量正常是单调递增的累计量，出现回退、跳变、与功率积分不一致，都说明链路有问题。
- 分工上的隔离：计量链路（DL/T 645 + IEC 102）应与生产控制链路分区，计量主站只允许采集终端访问，避免控制侧被攻陷后横向篡改电量。
- 依据说明：本篇关于 IEC 102 与 DL/T 645 的分工、典型数据均来自素材《工控协议.md》；发电量寄存器示例来自平原链点表；未做这两种协议的实测抓包。
