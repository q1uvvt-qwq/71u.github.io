## 一句话概括

日志异常检测走过三个阶段：人工规则、统计分布、模板序列建模，再到现在的语义表示学习。理解这条线要抓住一个分岔口，就是把日志压成模板 ID 还是保留原始文本语义。

## 三个阶段各自的适用与失效

规则匹配靠黑名单命令、敏感路径、危险端口、注册表项来识别已知威胁。可解释性最强，规则命中就是证据；对未知攻击和行为变体覆盖不足，而且规则集本身需要专家长期维护。

统计分析对事件频率、时间间隔、主机行为分布建模，指标显著偏离历史分布就告警。实现成本低，问题是理解不了复杂上下文：一条完全正常的命令出现在完全错误的前后文里，频率统计看不出来。

模板化方法先把原始日志解析成模板 ID，再把日志序列当离散符号序列建模。DeepLog 用序列预测思想判断下一个模板是否符合历史模式，LogAnomaly 进一步引入语义向量提高泛化。这条路在系统日志上效果稳定，因为系统日志的模板重复度非常高，模板 ID 序列几乎就是日志的全部信息。

模板化在 EDR 日志上失效。模板 ID 会压缩掉命令行参数、路径、IP、哈希这些字段，而这些恰是主机行为日志里判别攻击的主要依据。一条 `process_create` 事件，模板 ID 只知道"创建了进程"，不知道创建的是 `cmd.exe /c whoami` 还是 `powershell.exe -enc <base64>`。系统日志里这些细节不重要，EDR 日志里它们就是全部。

## 深度学习方法

- RNN：能建模模板序列的时序关系，但长序列上信息衰减，256 长度的窗口很容易把早期信息丢掉
- 自编码器：用重建误差判异常，适合无标签场景；问题是容易把高频噪声学成正常模式，训练集里常见的东西都被认为该重建得出来
- 图神经网络：把进程、文件、网络连接建行为图，表达跨实体关系的能力强；构图、存储、推理成本都高

主机行为日志有两个特点卡住这些方法：事件数量大、窗口跨度长，同时单条日志语义复杂。要同时处理长序列和保留逐位置解释入口，Transformer 是更合适的结构。

## Transformer 路线

BERT 类预训练思想进入日志领域后，形成了一条主线：用大量未标注日志学正常行为表示，再用重建误差、表示距离或异常分数发现偏离。

| 方法 | 输入粒度 | 依赖 parser | 主要计算瓶颈 | 阈值方式 |
| --- | --- | --- | --- | --- |
| LogBERT | 模板序列 | 是 | 日志解析 / Tokenization、Embedding、QKV / Attention / FFN、检测头 | 固定或按验证集定 |
| LAnoBERT | 原始日志 | 否 | 同上，另有重复日志的重复 BERT 推理 | 固定 |
| ADALog | 单条原始日志 | 否 | Tokenization、双向 Encoder、MLM 重构概率 | 正常集自适应百分位 |
| ContraLog | 原始消息序列 | 否 | Message Encoder、Sequence Encoder | 正常集分位数（Robust-MAD） |

LogBERT 用 BERT 式遮蔽语言建模学正常模板序列的模式，偏离正常模式的序列被判异常。它的瓶颈在 Transformer Encoder，另外还多一层 parser 依赖，解析器输出一变缓存就失效。

LAnoBERT 去掉了 parser，并提出了一个实用的推理优化：对重复日志或日志 key 建字典 / 缓存，减少重复的 BERT 推理。这条思路对缓存设计有直接迁移价值（见 [缓存](../03-轻量化/缓存.md)）。

ADALog 用双向预训练编码器加遮蔽语言建模，在正常日志上微调，把 token 级重建概率聚合成日志级异常分数，再用正常数据上的自适应百分位阈值检测。它的特点是面向单条非结构化日志，不做序列级上下文建模。

ContraLog 把预测目标从离散模板 ID 改成连续 message embedding，用 Message Encoder 加 Sequence Encoder 的双编码结构，同时结合遮蔽语言建模与对比学习。

"预测离散模板 ID"与"预测连续 embedding"的差别值得展开。前者的输出空间是一个有限词表，预测错一个模板就是一次明确的重建失败，判据清晰；但词表大小限制了表示能力的上限，模板里丢掉的细节找不回来。后者的输出空间是连续向量，模型必须学到一个有几何结构的表示空间，余弦距离才有意义；好处是细粒度信息能保留在向量的每一维里，坏处是训练更难、判据依赖距离度量是否合理。

## Contrastive 与 MLM 的结合

ContraLog 同时用两个目标。MLM 式的遮蔽重建让模型学会"根据上下文补全"，对比学习让模型学会"把相似的东西放近、不同的东西放远"。两个目标互补：重建管局部一致性，对比管全局结构。

这个组合在结构上带来一个额外好处：逐位置的输出天然支持解释。只输出窗口总分的模型，被问到"哪几条日志触发了告警"时只能靠事后归因；逐位置分数的模型直接把 256 个位置的分数摆出来，Top-K 就是候选证据。

## 共同局限

- 全部依赖"正常样本足够多、足够干净"这个前提。正常基线本身在漂移时，所有方法都会退化
- 全部需要一个阈值才能出二值判定，而阈值来自验证集分布，跨环境不通用
- 弱标签不能替代金标。规则产生的弱标签可以用来选数据，不能用来宣称检测性能
- 逐位置定位的召回普遍低于窗口级命中。窗口里只要有一个位置对，窗口就算命中，但定位要覆盖其中多数位置才有实用价值
